# Minara: вопросы владельцу

Решения по вопросам 9–10 ноября и что из них сделано (10 ноября, вечер).

## 1. Sonnet 4.6, Opus 4.6 и Fable 5 — сделано

Через `/v1/messages` Minara кэширует их на всех уровнях (замер 10 ноября: голова 5–13 тыс.
токенов записана и прочитана, цикл с инструментами продолжается без блоков мышления).
Теперь они публикуются, все их уровни идут этим путём. Тот же путь снял ограничение с
Opus 4.7, 4.8, 5 и Sonnet 5: `none`, `xhigh` и `max` идут через `/v1/messages` как есть.

## 2. `minara_min_credits` — 0, без изменений

Если минус нежелателен, поставьте `"minara_min_credits": 15` в `config.json`.

## 3. Default у Opus 4.7, Opus 4.8, Opus 5 и Sonnet 5 — `high`, без изменений

«Default» по-прежнему уходит как `high` в чат (канал с кэшем). Остальные уровни теперь
отправляются как есть (см. п. 1).

## 4. Повторный замер Minara — заменён слежением

Relay смотрит, с какого канала пришёл каждый ответ, и сам переводит уровень, попавший в чате
на канал без кэша, на `/v1/messages` (`cache.route_switched`). Новые модели, цены и ушедшие
модели он берёт сам каждые 6 часов (`minara_catalog_refresh_hours`, см. `docs/minara.md`,
«Каталог обновляется сам»). Перемеры по расписанию не нужны.

## 5. Исчерпанные аккаунты — удалены

Minara 1, 2, 28, 37, 42, 44 и 45 удалены из `config.json` 10 ноября в 09:31 (копия —
`config.json.20261110T093138.bak`); аккаунтов 69, из них Minara — 44.

## 6. Модели Minara в Claude Desktop — Fable 5.2 добавлен

В список Claude Desktop 3P добавлена одна строка: `minara/claude-fable-5-2`, «Fable 5.2
(Minara)». Остальные строки не тронуты. Видна после перезапуска Desktop и relay на новом коде.
