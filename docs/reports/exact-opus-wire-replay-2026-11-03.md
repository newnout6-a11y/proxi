## Границы трасс

Каталог `.agents/exact-replay/20261103-2115-opus-original/` содержит приватные
запросы, сырые ответы, нормализованные события, хронологию и manifest с хешами.
Он исключён из Git. Не отправляйте его целиком без проверки: там есть переписка.
Cookies и заголовки авторизации не записаны в заголовках трассы, но секреты
могут встречаться в самих телах, если пользователь включил их в сообщения.
Трасса видит HTTP-тело после обработки HTTP-клиентом, не TLS, не исходное
chunked-фреймирование и не запрос Retool к провайдеру.

Новые отключённые по умолчанию трассы клиента и upstream документированы в
README. Для следующего реального запроса ID из клиентской трассы включается в
имена папок попыток upstream. Они фиксируют исходное тело OpenCode, результат
разбора, события relay и записанный клиенту ответ. Запись ошибки после начала
SSE различает внешний HTTP 200 и внутренний статус ошибки. При ошибке записи
диагностика не должна заменять ответ модели. Это диагностика, а не устранение
пустого ответа Retool. Рабочий прокси не запускался и не перезапускался.
